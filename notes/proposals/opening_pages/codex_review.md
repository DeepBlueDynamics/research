# Codex counterarguments and concessions — working review

## Antigravity independent draft

Retain its explicit operational progression, structured ingestion/analytics/HMI objectives, and balanced uncertainty/nominal evaluation. Those make the proposal concrete.

Reject unsupported characterization of actual installed source inventory, legacy baseline timing (30–180 seconds / 60 seconds), high misclassification rates and forced binary selectors. The topic substantiates fragmentation, not these measurements. Remove rather than estimate.

A scenario can illustrate correlated false confidence; it cannot establish universal 100% coherent-spoof detection. Independent evidence may be stale, absent, correlated or insufficiently accurate. Residual disagreement is not proof that one named source is compromised. eLoran is RF, so the non-RF enumeration is incorrect; discuss distinct dependencies rather than declaring independence by modality.

The HMI objective says ECDIS-conformant despite acknowledging the UX-only clarification. Use familiarity target and specific chosen design practices, without a standards-conformance claim. An alert render callback must be validated as a measurement of presentation, not merely work queued to a renderer.

The KPP latency gate allows 1% ≥1-second events; that relaxes the source requirement. Report distribution and all misses; don't hide tail failures. Air-gapped operation is a source-stated architectural requirement, not an unverified assumption. A failed curl alone does not prove the application can function without a remote dependency.

The September 1 answer is not a human-research exemption. Rebranding timed participant trials and SUS/NASA-TLX as walkthroughs does not determine their status. Remove participant-study promises pending an appropriate determination. The August 28 Iron Bank answer does not answer runtime timing; retain that uncertainty. CUI wording does not automatically designate pre-existing public proposal materials as CUI.

Source registry entries using wildcard filenames and broad page claims need actual file/paragraph verification before reuse.

## Codex self-critique / concessions before peer review

The 60-case / 18-of-20 / 12-task / 9-of-12 numbers are budget-oriented proposals, not evidence-derived statistical thresholds. They can be changed by agreement if the final protocol retains useful/uncertain strata, clear denominators and frozen evaluation criteria. Zero failures in a finite suite is not a real-world reliability guarantee.

A third full interface could overrun the base budget. Prefer a feature-disabled version of the same unified interface as the third comparison arm; only the fragmented surrogate requires a separate minimal view. View-change counts can reward information crowding. They need evidence completeness and legibility/design checks and must remain proxies.

Sixty nominal/recoverable/unresolved cases alone do not specify adequate anomaly diversity. Define coverage of fault, jamming indicators, spoofing indicators, common dependency, stale data, missing metadata and recovery transitions. Include observation-equivalent case pairs to detect truth leakage; those pairs are intentionally not independent statistical draws.

The original latency row specifies four corner tests but not intermediate source counts or rates. Add a mixed-rate sweep for 4–7 sources and measure startup/recovery separately. Injection onset and ingestion timestamps answer different questions.

The Page 1 prose must make the product benefit central; too much experiment detail can make this look like a simulator proposal. Keep the independence insight but shorten evaluator mechanics in the shared prose.

## Claude independent draft

Retain the three operator questions and the useful distinction between available information and certainty. Its current maritime evidence can motivate the problem, but the two-page proposal should avoid spending scarce space on commercial incident counts or implying their validation by the Navy. Prefer one direct maritime-government source.

Remove the blanket assertion that existing standards define per-source integrity only; its own cited description includes cross-source consistency. The build plan is not evidence of universal coherent-spoof detection. A clock alone cannot generally resolve a position discrepancy, and independent source availability remains conditional.

The K3 claim that 35/class gives ±0.10 at 95% is not valid without a specified proportion and interval calculation; worst-case precision is wider. A scripted 'follow first alarm' baseline risks constructing a weak comparator. Do not claim calibration or Expected Calibration Error for an ordinal assurance level: probability definition and calibration data would first be required. Retain risk/coverage as a useful analysis, with observable-evidence scoring rather than hidden-truth diagnosis alone.

The original percentile latency row and unsafe-action allowances conflict with the strengthened constraints/finite-suite conservative gate. Keep strict latency and zero unsupported definitive advice on unresolved held-out cases, paired with useful performance on recoverable cases.

## Grok independent draft

Retain its government maritime advisory and disciplined distinction between policy context and actual interface specifications. Its source/claim labels and absence of fabricated baseline timing are strong.

The opening 'does not lack sources' overstates a universal condition. Say operators face a growing number of sources, without guaranteeing any particular source is available in the case. Page 1 is too long for the requested allocation.

The K1 failure condition says sources outside the envelope fail; the requirement is capability within it, not a prohibition on additional capacity or rejection of safely handled off-envelope inputs. Testing one nominal configuration does not establish the full envelope.

Twenty-four scored development runs plus four holdouts is too thin for strong generalized claims. Score only frozen holdouts for final gates and report strata. A source being independent does not alone make a fault/jam/spoof label identifiable. Mixed causes, limited precision and stale observations still matter.

'No unauthorized egress' permits authorized remote dependencies; the user requires an airgap. Verify zero external communication and offline functional completeness, allowing only the declared internal network. Iron Bank timing remains unanswered, not established as a Phase II-only requirement.

## Security clarification applied to Codex draft

Added a secured-runtime KPP following the user's explicit clarification. Security testing must run with the same hardening enabled during latency tests. Signing/pinning is a package integrity check; it is not proof of origin trust without a controlled trust anchor. Offline vulnerability results need scanner/database dates. Authenticated access, least privilege, protected records/keys and tamper tests belong in a declared threat model. A finite test gate is not an accreditation claim.

No performance or operator benefits have been measured by this writing exercise. Independent draft files are retained for comparison; Antigravity reports it amended its own draft after the user's security clarification.
