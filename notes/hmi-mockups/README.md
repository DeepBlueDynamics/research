# HMI mockups

## Current reference: `apnt-console.html`

**`apnt-console.html`** is the working design-system reference — an interactive,
S-52-styled ECDIS-N console built as widgets (confidence tiles, source roster,
agreement matrix, divergence scatter, BAM degradation banner, COA cards, retrieved-
procedure panel, replay scrubber). Toggle **Nominal ⇄ GNSS-Degraded** to see the
full alert → evidence → COA → procedure flow, and **Day / Dusk / Night** to see the
S-52 palette conformance. Published artifact:
https://claude.ai/code/artifact/f92e6605-6f0c-44ae-8aa2-2030698e4915

This supersedes the four concept images below for layout/symbology reference.
It is still **notional** — not a certified navigation system, and the chart canvas
is a stylized schematic, not real ENC data.
